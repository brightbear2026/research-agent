# 最小公开样例

这个样例展示仓库实际交付物的形态：读者报告、引用索引、证据矩阵和资料缺口。内容是对本仓库公开实现的可复核审计，不是虚构行业研究。

- `report/research_report.md`：规范 Markdown 叙事
- `data/citations.csv`：全局引用索引
- `evidence/evidence_matrix.csv`：结论—证据关系
- `evidence/research_gaps.md`：明确披露未覆盖范围

完整运行会额外生成 HTML、截图索引、结构化数据表、`chapter_meta.json` 和声明账本。为保持仓库轻量，本样例仅提交便于人工阅读的核心文件。
