# 来源可信度分级表（Source Rubric）

依据研究规范第 5 节。关键结论不得仅依赖 C/D 级来源。

## A 级：高可信度（一手原始来源）
- 政府原始文件 / 法律法规 / 国家标准原文
- 同行评审论文（顶刊、顶会）
- 企业财报、年报、招股书、投资者材料
- 官方技术文档、白皮书、产品文档
- 国际组织（IMF/WTO/IEA/IEEE/OASIS 等）原始报告
- 原始数据集、专利文件
- 人物**完整**演讲/访谈原文（非媒体二次总结）

## B 级：较高可信度
- 权威研究机构 / 智库报告（RAND/Gartner/IDC/IEA/中国信通院 等）
- 高质量行业协会报告
- 知名咨询公司报告
- **具名券商/投行研报**（可获得完整报告，机构、分析师、发布日期、方法与原始链接可识别）
- 主流财经/科技媒体**深度**调查报道（FT/Reuters/NYT/Bloomberg/财新/36氪深度 等）
- 高质量专家分析（具名、有方法论披露）

## C 级：一般可信度
- 普通行业媒体、企业营销材料
- 二手转载、未完整披露方法的数据报告
- 专业人士个人博客 / 文章（有署名但无同行评审）

## D 级：低可信度（仅作线索）
- 无署名文章、来源不明数据
- 自媒体转述、无法验证的社媒内容
- 明显营销软文
- AI 生成但无原始来源的内容

## 交叉验证规则（第 2.5 节）
对以下信息原则上至少 2 个相互独立来源验证：
> 市场规模、增长率、公司收入、用户数、产品性能、技术优势、市场份额、行业排名、重大事件、人物重要观点、趋势判断、政策影响、客户数量、投融资数据。

来源冲突时的处理顺序：
1. 列出不同来源的数据；2. 说明统计口径；3. 说明时间范围；4. 分析差异原因；5. 给出更可信的数据范围；6. **不得简单二选一**。

## 券商研报专项规则

券商研报擅长提供产业链拆解、盈利预测、专家访谈线索和市场一致预期，但它是卖方机构的分析产品，不是被研究公司或行业数据的原始出处。使用时遵守以下规则：

1. **分级不自动上调**：完整、具名、可追溯且披露方法的券商/投行研报通常为 B 级；只有摘要、截图或转载片段时降为 C 级；来源不明的“研报数据”聚合页为 D 级，仅作线索。研报引用财报、政策、标准或数据库时，应回溯并另行登记原始来源，不能因被研报引用就把二手数据当作 A 级。
2. **观点不写成事实**：评级、目标价、盈利预测、市场空间测算、渗透率预测和情景假设统一标为 `【机构观点·券商名称·发布日期】`。历史财务数字、行业数据等事实仍须核对原始出处。
3. **保留预测口径**：记录机构、分析师、报告类型、覆盖对象、发布日期、页码、预测区间、关键假设、估值方法、币种、评级/目标价（如适用）、利益冲突披露和访问限制。数字必须保留单位、统计时间、地域/范围与定义。
4. **独立性按研究生产者计算**：同一份研报在官网、资讯平台和转载站出现多次，只算一个来源；同一券商研究所的多份同方向报告默认属于同一 `independence_group`。仅当底层报告分别可识别、单独登记并具有独立分析时，“一致预期”才可拆分计数。
5. **必须交叉验证**：券商研报不得成为关键事实或数值结论的唯一来源。优先与企业披露、政府/协会数据、原始数据库或另一家独立机构交叉验证；预测分歧进入 `evidence/controversy_matrix.csv`，正文给条件性结论。
6. **尊重访问与版权**：不绕过登录、验证码、付费墙或授权控制；不传播未授权全文。只摘录支撑论点所需的短片段或关键页，并登记页码和访问状态；无法取得完整报告时披露资料缺口。
